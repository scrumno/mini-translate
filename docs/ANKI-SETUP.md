# Настройка интеграции с Anki

Пошаговая инструкция по развёртыванию приложения «Переводчик» и подключению сохранения в Anki.

---

## 1. Требования

- **Go** 1.21+ (для сборки бэкенда)
- **Node.js** 18+ и npm (для сборки фронтенда)
- **Wails v2** CLI: `go install github.com/wailsapp/wails/v2/cmd/wails@latest`
- **Anki** с установленным плагином [AnkiConnect](https://github.com/FooSoft/anki-connect) (для кнопки «В Anki»)

---

## 2. Настройки: интерфейс или .env

Все параметры можно задать **в приложении**: откройте **Настройки** (иконка шестерёнки в заголовке окна). Конфиг сохраняется в файл (например, в каталог конфигурации пользователя) и применяется без перезапуска (кроме флага логов фронта).

Альтернатива — переменные окружения и файл `.env` (удобно при первом запуске или в CI).

### Бэкенд (в папке `desktop/`)

```bash
cp .env.example .env
```

Основные переменные (дублируют поля в Настройках):

| Переменная | Описание | Пример |
|------------|----------|--------|
| `TRANSLATOR_DEBUG` | Логи бэкенда (true/1 — включить) | `false` |
| `ANKI_CONNECT_URL` | URL AnkiConnect | `http://127.0.0.1:8765` |
| `ANKI_DECK_WORDS` | Колода для слов | `English/Words/Default` |
| `ANKI_DECK_PHRASES` | Колода для фраз | `English/Phrases` |
| `ANKI_NOTE_TYPE_WORDS` | Тип заметки для слов | `TranslatorWord` |
| `ANKI_NOTE_TYPE_PHRASES` | Тип заметки для фраз | `TranslatorPhrase` |

### Фронтенд (в папке `desktop/frontend/`)

```bash
cp .env.example .env
```

| Переменная | Описание |
|------------|----------|
| `VITE_DEBUG` | Логи в консоли браузера: `true` или `false` (в Настройках — «Логи фронта»; после смены нужна перезагрузка приложения) |

---

## 3. Сборка и запуск

1. Клонируйте репозиторий и перейдите в каталог проекта.

2. Соберите фронтенд:
   ```bash
   cd desktop/frontend
   npm install
   npm run build
   cd ..
   ```

3. Запустите приложение (из каталога `desktop/`):
   ```bash
   wails dev
   ```
   Или соберите бинарник:
   ```bash
   wails build
   ```
   Исполняемый файл появится в `desktop/build/bin/`.

4. **Конфиг:** при первом запуске можно использовать `.env` в текущей рабочей директории (для `wails dev` — каталог `desktop/`). После сохранения настроек через интерфейс приложение пишет конфиг в файл (каталог конфигурации пользователя), и `.env` больше не обязателен для работы.

## 4. Настройка Anki

### 4.1. Установка AnkiConnect

1. Откройте Anki.
2. Меню **Инструменты** → **Дополнения** → **Получить дополнения**.
3. Введите код дополнения AnkiConnect (см. [страницу плагина](https://github.com/FooSoft/anki-connect)).
4. Перезапустите Anki. AnkiConnect по умолчанию слушает порт 8765.

### 4.2. Типы заметок

Создайте два типа заметок, как описано в **templates/anki/README.md**:

- **TranslatorWord** — поля: Word, Translation, Transcription, PartOfSpeech, Example_EN, Example_RU, Context, Tags, Source, Added. Три шаблона карточек (узнавание, производство, контекст).
- **TranslatorPhrase** — поля: Phrase, Translation, Example_EN, Example_RU, Context, Tags, Added. Два шаблона карточек.

**Что именно вставлять в лицевую и оборотную сторону каждой карточки** (готовый HTML с `{{Поле}}`) — см. раздел «Card templates» в **templates/anki/README.md**.

Стили карточек скопируйте из `templates/anki/card-styles.css` в окно «Стили» типа заметки.

### 4.3. Колоды

Создайте колоды с именами, указанными в настройках приложения или в `.env` (например `English/Words/Default` и `English/Phrases`).

### 4.4. Проверка

1. Запустите Anki.
2. В приложении введите слово (например «apple»), переведите.
3. Нажмите **В Anki**. Должна создаться заметка в указанной колоде. Если появится ошибка — проверьте, что Anki запущен, AnkiConnect включён, имена колод и типов заметок совпадают с настройками (в приложении: Настройки → Anki).

---

## 5. Использование

1. **Перевод:** введите текст, выберите языки, нажмите Enter или кнопку перевода. Для одного слова приложение может подтянуть транскрипцию и примеры из словаря (Free Dictionary API) при сохранении в Anki.
2. **В Anki:** после успешного перевода нажмите **В Anki**. Для слов создаётся заметка с полями словаря (если доступно); для фраз — упрощённая заметка. Дубликаты в одной колоде не создаются.
3. При ошибках (Anki не запущен и т.п.) сообщение появится под кнопками.

---

## 6. Развёртывание для другого пользователя

1. Клонировать репозиторий.
2. Установить Go, Node.js, Wails (см. требования).
3. В `desktop/` скопировать `.env.example` в `.env` и задать:
   - `TRANSLATOR_DEBUG` / `VITE_DEBUG` — по желанию;
   - `ANKI_CONNECT_URL`, колоды и типы заметок — под свой Anki.
4. В `desktop/frontend/` скопировать `.env.example` в `.env`, при необходимости выставить `VITE_DEBUG`.
5. Собрать фронтенд: `cd desktop/frontend && npm install && npm run build && cd ..`.
6. Собрать приложение: из `desktop/` выполнить `wails build`.
7. Передать пользователю бинарник из `desktop/build/bin/`. Настройки можно задать в интерфейсе приложения (Настройки); при первом запуске можно положить `.env` рядом с бинарником или задать параметры вручную в Настройках.
8. Пользователь должен установить Anki + AnkiConnect. Инструкцию по типам заметок и стилям взять из `templates/anki/README.md` и этого файла.

Все настраиваемые значения можно задать в **Настройках** в интерфейсе приложения (конфиг сохраняется в файл) или через `.env`; жёстко прописанных путей в коде нет.
