# Шаблоны для Anki и Obsidian

Эта папка содержит стили и примеры для интеграции приложения «Переводчик» с Anki и Obsidian.

- **anki/** — стили карточек Anki (`card-styles.css`) и инструкция по созданию типов заметок (`README.md`).
- **obsidian/** — примеры формата заметок (слово, фраза) и таблицы индекса. Приложение генерирует заметки по этой структуре автоматически; шаблоны здесь для справки и ручного редактирования.

Подробная настройка и использование — в документе docs/ANKI-OBSIDIAN-SETUP.md в корне проекта.
