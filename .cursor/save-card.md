# ТЗ: Obsidian + Anki — структура данных

## Obsidian

### Структура файлов

```
📁 Vault/
└── 📁 Vocabulary/
    ├── 📁 Words/
    │   ├── apple.md
    │   ├── ubiquitous.md
    │   └── ...
    ├── 📁 Phrases/
    │   ├── to pull someone's leg.md
    │   └── ...
    └── _index.md   ← сводная таблица всех слов
```

Слова и фразы разделены, потому что у них разная логика карточек и заметок.

---

### Как выглядит заметка на слово (`apple.md`)

```markdown
---
word: apple
translation: яблоко
transcription: /ˈæp.əl/
part_of_speech: noun
tags: [vocabulary, food, beginner]
source: book/friends-series/work
added: 2024-03-15
anki_added: true
---

# apple /ˈæp.əl/

**яблоко** · существительное

## Значения
1. Яблоко (фрукт)
2. Apple — название компании (переносное)

## Примеры
- *An apple a day keeps the doctor away* — Яблоко в день и врач не нужен
- *She took a bite of the apple* — Она откусила яблоко

## Мой контекст
> Встретил в книге "Atomic Habits", глава 3

## Синонимы / связанные слова
- [[pear]] · [[fruit]] · [[orchard]]

## Заметки
_здесь можно дописать вручную что угодно_
```

### `_index.md` — сводная таблица

Автоматически обновляется при каждом добавлении.

```markdown
# Vocabulary Index

| Слово | Перевод | Часть речи | Тег | Дата |
|-------|---------|------------|-----|------|
| [[apple]] | яблоко | noun | food | 2024-03-15 |
| [[ubiquitous]] | вездесущий | adj | advanced | 2024-03-14 |
```

Это удобно открывать в Obsidian как дашборд словаря.

## Anki

### Типы карточек

Для **одного слова** создаётся **3 карточки** автоматически — это стандартная практика для языкового Anki.

---

#### Карточка 1 — Узнавание (EN → RU)

```
ЛИЦЕВАЯ:
┌─────────────────────────┐
│  ubiquitous             │
│  /juːˈbɪk.wɪ.təs/      │
│                         │
│  [adjective]            │
└─────────────────────────┘

ОБОРОТНАЯ:
┌─────────────────────────┐
│  вездесущий, повсеместный│
│                         │
│  📖 Пример:             │
│  Smartphones have become│
│  ubiquitous in modern   │
│  life.                  │
│                         │
│  🏷 technology, advanced │
└─────────────────────────┘
```

---

#### Карточка 2 — Производство (RU → EN)

```
ЛИЦЕВАЯ:
┌─────────────────────────┐
│  вездесущий             │
│  [adjective]            │
│                         │
│  Как это по-английски?  │
└─────────────────────────┘

ОБОРОТНАЯ:
┌─────────────────────────┐
│  ubiquitous             │
│  /juːˈbɪk.wɪ.təs/      │
│                         │
│  📖 Smartphones have    │
│  become ubiquitous...   │
└─────────────────────────┘
```

---

#### Карточка 3 — Контекстная (заполни пропуск)

```
ЛИЦЕВАЯ:
┌─────────────────────────┐
│  Вставь слово:          │
│                         │
│  "Smartphones have      │
│  become _________ in    │
│  modern life."          │
└─────────────────────────┘

ОБОРОТНАЯ:
┌─────────────────────────┐
│  ubiquitous             │
│                         │
│  вездесущий             │
└─────────────────────────┘
```

Третья карточка создаётся **только если есть пример** — то есть почти всегда, потому что примеры тянутся из словаря автоматически.

---

### Для идиом/фраз — другой шаблон (2 карточки)

**Карточка 1** — что значит фраза:
- Лицевая: `to pull someone's leg`
- Оборотная: перевод + пример + пометка [idiom]

**Карточка 2** — как выразить мысль:
- Лицевая: `Как сказать "разыгрывать кого-то" (идиома)?`
- Оборотная: `to pull someone's leg` + пример

---

### Поля карточки (Note Fields в Anki)

Под капотом одна запись в Anki содержит все поля, из которых генерируются карточки:

```
Word          → ubiquitous
Translation   → вездесущий, повсеместный
Transcription → /juːˈbɪk.wɪ.təs/
PartOfSpeech  → adjective
Example_EN    → Smartphones have become ubiquitous in modern life.
Example_RU    → Смартфоны стали повсеместными в современной жизни.
Context       → Встретил в книге Atomic Habits
Tags          → technology, advanced
Source        → book
Added         → 2024-03-15
```

---

### Структура колод в Anki

```
📦 English/
├── 📂 Words/
│   ├── Beginner
│   ├── Intermediate  
│   └── Advanced
├── 📂 Idioms/
└── 📂 Phrases/
```

Колода выбирается автоматически по тегу сложности, либо вручную в момент добавления.

---

## Связь между Obsidian и Anki

Поле `anki_added: true` в frontmatter заметки означает, что карточка уже создана — утилита проверяет это перед добавлением, чтобы не плодить дубликаты. В идеале также хранить `anki_id` — числовой ID карточки из Anki, чтобы можно было её обновлять при редактировании заметки.

```markdown
---
anki_added: true
anki_id: 1709823451234
---
```
