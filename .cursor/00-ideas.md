ТЗ: Утилита для перевода с интеграцией Anki и Obsidian
Суть
Минималистичный десктопный инструмент (или веб-приложение) — вводишь слово/фразу, получаешь перевод, и всё автоматически летит в Anki и Obsidian. Никаких лишних кликов.

Ядро функционала
Перевод
Поле ввода с автоматическим определением языка (например, ввёл по-английски — перевод на русский, и наоборот). Поддержка одиночных слов, фраз и коротких предложений. Для слов — дополнительно показывать транскрипцию и примеры употребления из словаря (через словарный API типа Free Dictionary API или Yandex Dictionary).
Отправка в Anki
Через AnkiConnect (локальный плагин для Anki). Карточка создаётся автоматически: лицевая сторона — оригинал + транскрипция, оборотная — перевод + пример предложения. Можно выбирать колоду перед добавлением или задать дефолтную в настройках.
Отправка в Obsidian

Через Obsidian Local REST API (плагин) или просто запись в файл через файловую систему. Каждое слово добавляется строкой в специальный файл-дневник (vocabulary.md) с датой, оригиналом, переводом и примером. Либо создаётся отдельная заметка на каждое слово с тегом #vocabulary.
